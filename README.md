# ResumeRAG

An interactive tool for letting anyone talk to your resume. RAG-based UI component for NextJS

## Building a Docstore

You can build a docstore from a collection of inputs to enable interactive querying.

### Supported Input Formats
- **CSV Files**: The CSV files should have the following columns:
    - `question`: The question text.
    - `answer`: The corresponding answer text.

### Unsupported Formats
- **PDF Files**: PDF files are not yet supported.

To get started, ensure your input files are properly formatted and follow the supported formats.
